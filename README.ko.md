# bumpist-design

디자인 토큰과 React 디자인 시스템입니다. 테마 6종 × 라이트·다크 × 프로필 2종(소비자형·작업 공간형)이고, 모든 테마가 디자인 원칙 9개를 지킵니다. Bumpist Suite의 디자인 층이지만 단독으로 쓸 수 있습니다.

> **상태: v0 (0단계).** 계약 C1(테마)·C2(카탈로그) 스키마와 첫 테마 초안(paper)만 있습니다. 토큰 빌드, 컴포넌트, Storybook은 1단계에서 추가됩니다.

`pnpm check:schemas`는 스키마 형식과 함께 원칙 UI-003(순백·순흑 금지)과 UI-005(라운드 12·16px)를 검사합니다.
